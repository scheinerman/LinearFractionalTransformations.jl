Construction

A linear fractional transformation is built from its four coefficients, from a 2×2 matrix, or from the images of three points.

f = LFT(1, 2, 3, 4)             # z -> (z + 2) / (3z + 4)
g = LFT([1 2; 3 4])             # same map, from its matrix
h = LFT(0, 1, Inf, 1, 2, 3)     # 0 -> 1, 1 -> 2, Inf -> 3

The constructor overloads:

FormResult
LFT(a, b, c, d)the map with those coefficients
LFT(M::AbstractMatrix)from the 2×2 matrix [a b; c d]
LFT(a, b, c)a ↦ 0, b ↦ 1, c ↦ ∞
LFT(a, aa, b, bb, c, cc)a ↦ aa, b ↦ bb, c ↦ cc
LFT(a => aa, b => bb, c => cc)pair form of the six-point constructor
LFT()the identity, LFT(1, 0, 0, 1)
LFT(::Type{T})the identity of type T

The four coefficients are promoted to a common type, so LFT(1, 2.0, 3, 4) has Float64 coefficients. Infinite coefficients are rejected, as is a singular coefficient vector with ad - bc == 0.

LinearFractionalTransformations.LFT — Type
LFT{T} <: Function

A linear fractional transformation f(z) = (a*z + b) / (c*z + d) with coefficients a, b, c, d in the field T and a*d - b*c != 0.

The coefficients are four fields of the same name, promoted to a common type. That type may be any field: Int, Rational, Complex, or an exact field such as a Nemo number field.

Constructors:

  • LFT(a, b, c, d): the map with those coefficients. Infinite and singular coefficient vectors are rejected.
  • LFT(M): the map with coefficient matrix M = [a b; c d].
  • LFT(): the identity, LFT(1, 0, 0, 1).
  • LFT(a, b, c): the map a ↦ 0, b ↦ 1, c ↦ ∞. Inf and ∞ are permitted.
  • LFT(a, aa, b, bb, c, cc) or LFT(a=>aa, b=>bb, c=>cc): the map a ↦ aa, b ↦ bb, c ↦ cc.
